Deep Dive

ourSuburb 프로젝트에서 배포 환경에서만 발생한 지도 포커스 오류

LOCAL 정상

suburb를 선택하면 지도가 해당 위치로 이동하였습니다.

HOSTING 오류 발생

같은 동작에서 지도 카메라가 이동하지 않았습니다.

1. 증상

호스팅 환경에서 suburb를 선택해도 지도 카메라가 해당 위치로 이동하지 않았습니다. 로컬에서는 같은 동작이 정상으로 동작하였습니다.

↓
2. 재현

같은 suburb 선택 시나리오를 로컬과 호스팅에서 각각 실행하였습니다. 호스팅에서만 문제가 났습니다.

↓
3. 원인

Mapbox 스타일 로딩 시점과 지도 컨테이너 크기를 확인하였습니다. 스타일이 로드되기 전에 flyTo가 실행되었고, resize 처리가 빠져 있었습니다.

↓
4. 조치

isStyleLoaded 확인과 resize 처리를 추가하였습니다.

if (!map.isStyleLoaded()) {
  map.once('idle', () => moveCamera(lng, lat));
  return;
}
map.resize();
map.flyTo({
  center: [lng, lat],
  essential: true
});
↓
5. 재검증

수정 후 호스팅에서 같은 suburb 선택 시나리오를 다시 실행하였습니다. 선택한 위치로 지도가 이동하는 것을 확인하였습니다.

↓
6. 이슈 공유

LeanKit에 재현 환경, 재현 절차, 실제 결과, 기대 결과, 원인, 수정 내용을 적어 공유하였습니다.
